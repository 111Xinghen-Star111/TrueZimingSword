# 真紫冥剑 TrueZimingSword · v44 实验版

《影之刃零》PC 版 UE4SS Mod。以独立的“紫冥剑·实验”武器接入轻重连招、激光和三段大招。

**这是实验版。玩家已实机确认“重轻轻”和“重重重轻轻”的镜头问题已修复；v44 的断招修复仍待单独实机确认，红光、蓝光与投技抗控制也尚未完成实机验收。**

## 下载

下载 [Releases 中的 TrueZimingSword-v44.zip](https://github.com/111Xinghen-Star111/TrueZimingSword/releases)。请用这个安装包；GitHub 自动生成的 `Source code (zip)` 不是安装包。

压缩包只包含运行所需 Lua、一个原生桥接 DLL、安装与备份脚本、说明及校验清单。没有游戏资产、UE4SS 加载器、开发探针、录像、日志或个人存档。

## 兼容条件

- Windows 64 位，Steam Build **26367565**。
- 对应文件：游戏根目录下的 `platform\steam\PBZ.exe`，不是 `steam\PBZ.exe`。
- 该 EXE 的 SHA-256 必须为：

  ```text
  4415933CE33476F14C837ABB61A1B60AF8B78CD81783896501913A7AAC69E423
  ```

- 已安装兼容本游戏的 UE4SS，已验证的版本为 **v3.0.1-1195-g1ceefac8**。可从 [KintaroModding 的 PBZ 适配发布页](https://github.com/KintaroModding/ue4ss/releases/tag/v3.0.1-1195-g1ceefac8) 下载 `phantombladezero_ue4ss_v3.0.1-1195-g1ceefac8.zip`，按照该项目说明解压到 `platform\steam\`。
- UE4SS 应启用游戏线程延迟执行所需的 EngineTick / ProcessEvent 功能。该 PBZ 适配包提供游戏所需配置；不要拿别的游戏的 UE4SS 配置覆盖。
- 至少已有一个游戏存档。安装程序需要先制作备份。

安装程序会拒绝不匹配的游戏 EXE，不会为其他版本强行启用。中文路径尚未单独验证，建议游戏与备份目录使用英文路径。

## 安装

1. **退出游戏。** 如果正在使用旧实验版，先进入存档按 `Ctrl+Alt+F8` 清理、确认换回原版武器并保存，再退出。
2. 安装上面链接的 PBZ 适配版 UE4SS。本安装包不会替换 UE4SS 本体或其配置。
3. 把本压缩包完整解压。双击 `Install.cmd`，输入游戏根目录，例如 `D:\SteamLibrary\steamapps\common\PBZ`。
4. 等待出现 `Installed TrueZimingSword v44` 与 `Verified save backup`。
5. 正常启动游戏、载入存档，装备一把正常的主武器，再在游戏窗口按 **Ctrl+Alt+F10** 启用实验剑。

也可以在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -GameRoot "D:\SteamLibrary\steamapps\common\PBZ"
```

安装程序先校验包内文件，再逐份备份并校验存档及旧 Mod，然后复制运行文件。默认备份放在游戏根目录的同级 `TrueZimingSword-Backups` 文件夹中；它会显示实际路径。可用 `-BackupRoot "D:\PBZ-Mod-Backups"` 指定其他游戏目录以外的位置。

安装后的主要位置：

```text
PBZ/
└─ platform/steam/ue4ss/Mods/TrueZimingSword/
   ├─ enabled.txt
   ├─ Scripts/                 # Mod 运行脚本
   └─ Native/                  # 原生桥、安装后生成的备份标记
```

**不要只复制 Scripts。** 本 Mod 还需要原生桥与安装程序生成的本机备份标记。压缩包不携带任何人的存档或可直接复用的备份标记。

## 按键与连招

**[完整连招表（v44）](COMBOS.md)**：23 条轻重击路线、三段大招按法与衔接时机。

| 操作 | 按键 |
| --- | --- |
| 启用 / 检查实验剑 | **Ctrl+Alt+F10** |
| 清理实验剑、恢复原版武器 | **Ctrl+Alt+F8** |
| 轻击 L | 游戏中的轻击键 |
| 重击 F | 游戏中的重击 / 杀气攻击键 |
| 大招 Q | 游戏中的战技 / 大招键 |
| 闪避 | 游戏原本的闪避键 |

L、F、Q 表示输入类型，不要求按字母键；修改游戏键位后仍跟随对应游戏输入。

常用路线：

| 路线 | 输入 |
| --- | --- |
| 连续轻击 | L → L → L → L → L |
| 激光 | L → F → F |
| 激光后接腾空收尾 | L → F → F → L |
| 重轻轻 | F → L → L |
| 重重轻轻 | F → F → L → L |
| 重重重轻轻 | F → F → F → L → L |
| 三段大招 | 每段临近衔接时或收招后按一次 Q |

普通攻击不会缓存提前按下的后续招式；请在当前动作允许衔接时再按。收招后保留约 **1 秒**连招分支识别，停顿过久或闪避、换武器等中断会重新起手。

大招下一段提前输入只保留 **0.25 秒**。不要在第一段开头连按三次 Q 排完整轮；过早输入会过期。本轮大招只在第一动作扣一次次数，闪避或普通攻击切出会清掉后续排队。

候选动作浏览按键 `Ctrl+Alt+F2/F4/F5/F6` 仍属于实验调试功能，部分候选被主动禁用，不是正式连招必需操作。

## 当前参数

- 武器面板基础属性按原始配置 **×1.5**，原本为 0 的项目仍为 0。
- 前两段普通轻击 **1.6 倍速**，同步推进动画和命中时间线。
- 已识别的轻击物理伤害按调整前 **×0.5**；削韧不随这次减伤改变。
- 激光自身物理系数相对原始 **×4**，削韧保持原值。
- 大招第三段额外物理倍率相对原生 **×4**，即在前一版额外 ×2 的基础上再 ×2；不代表实际扣血一定严格同倍数。
- 大招 Start 前摇阶段 **1.5 倍速**，进入出手阶段后恢复原速。
- 三段大招搜索 **50 米**内当前场景的合法敌人并平滑贴近；碰撞会阻挡移动，不穿墙，也不会加载场景外敌人。
- 大招包含霸体标签、外部取消保护及强制受击 / 投技入口保护；主动闪避和切招会定向解锁。不是无敌，伤害仍结算，红蓝光与投技完全抗控制尚待验证。

## v44 修复与验证边界

- 修正轻击减伤检查误拒绝“重重重轻”准备动作的问题，并检查能力的其他私有时间线，保留没有直接伤害节点的合法动作。
- 腾空镜头拒绝贴近人体或起点穿透的碰撞结果；尝试其他安全机位，全部受阻时临时交回原生镜头，随后恢复。
- 当前开发版 **32 项离线检查通过**。玩家已实机确认“重轻轻”和“重重重轻轻”的镜头问题已修复；“重重重轻轻”实际连续性，以及真实红光 / 蓝光 / 投技抗控制仍待单独实机确认。
- 由其他能力或尚未识别的发射方式产生的间接伤害，不能仅凭当前离线检查认定倍率已覆盖。

## 停用、更新与卸载

1. 进入存档，按 **Ctrl+Alt+F8**，确认切回原版武器。
2. 确认清理成功后保存并退出游戏。
3. 卸载时移走 `platform\steam\ue4ss\Mods\TrueZimingSword` 文件夹；保留外部 `TrueZimingSword-Backups`。
4. 更新时保持游戏关闭，运行新包的安装脚本；它会重新备份当前存档和旧 Mod。

请勿在仍装备实验剑、尚未清理时直接删除 Mod。安装程序不自动恢复存档；需要恢复时先保留当前存档副本，再按备份清单人工核对，避免覆盖新进度。

## 常见问题

**Ctrl+Alt+F10 没反应**：确认游戏窗口在前台、已经载入存档、UE4SS 成功加载。若 `ue4ss\Mods\mods.txt` 中手动写有 `TrueZimingSword : 0`，请改为 `1`。每次更新后完整重启游戏。

**提示未准备备份标记或找不到桥接 DLL**：不要从开发目录零散复制脚本；完整解压并重新运行本包 `Install.cmd`。不要复制别人的 `held-inventory.arm`。

**Unsupported PBZ.exe build / PREFLIGHT_REJECTED**：当前 EXE 不匹配或原生预检失败，停止启用；不要绕过构建检查。

**安装提示权限不足**：检查游戏目录和备份目录是否可写；必要时以管理员身份运行安装脚本。

**清理失败**：保留 Mod 与备份。在装备界面先换回正常主武器，再按 Ctrl+Alt+F8；可在 `platform\steam\ue4ss\UE4SS.log` 中查看 `[TrueZimingSword]` 记录。公开反馈前请删去个人路径和存档信息。
